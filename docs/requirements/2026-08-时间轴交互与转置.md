# 时间轴交互与转置

## 基本信息

- 优先级：P1
- 状态：已完成
- 提出时间：2026-08-04
- 目标版本：Raidline v2

## 目标

让时间轴支持横竖转置、设备本地缩放、施法段与持续段，并保持鼠标、键盘和触屏均可操作。

## 功能要求

- 支持时间横向/人员纵向与时间纵向/人员横向两种布局。
- 首次打开时桌面默认横向、手机默认纵向；方向按设备和计划记忆。
- Ctrl+滚轮只在时间轴内阻止页面缩放，改为以指针为中心缩放时间轴。
- 缩放不写入计划；保留滑杆和按钮。
- 机制与技能显示施法段和效果段，0 与未知值必须明确区分。
- 关联技能保存相对机制伤害时刻的偏移，移动机制时同步移动。

## 验收标准

- [x] 两种轴向的时间定位、拖动和选择一致
- [x] Ctrl+滚轮不会在时间轴内缩放浏览器页面
- [x] 时间轴外仍保留浏览器默认缩放
- [x] 零长度、未知长度和正常长度显示正确
- [x] 桌面与手机浏览器验收通过

## 验收结果

- 桌面默认时间横向，手机默认时间纵向；编辑页与只读页均可即时转置。
- 查看方向、缩放及面板状态使用按计划、按设备区分的本地偏好键，不写入计划正文。
- 非被动滚轮监听仅绑定时间轴滚动容器，且只在 `Ctrl` 按下、指针位于容器内时拦截；范围、缩放边界和指针锚定均有单元测试。
- 浏览器已检查横向/纵向画布、阶段线、施法/持续段以及按钮和滑杆缩放替代操作。
