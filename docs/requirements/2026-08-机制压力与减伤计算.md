# 机制压力与减伤计算

## 基本信息

- 优先级：P1
- 状态：已完成
- 提出时间：2026-08-04
- 目标版本：Raidline v2

## 目标

基于机制固定伤害、持续伤害、目标范围与显式防御技能，给出可解释的最高个人治疗需求、团队伤害和逐人明细。

## 数据与规则

- 机制伤害为每目标固定数值，区分物理与魔法；不同目标或类型拆成不同机制。
- 支持直接伤害与按间隔跳伤，施法长度和持续时间均可为 0。
- 不维护血条，不扣除计划治疗，不推测护甲、格挡、天赋或常驻治疗。
- 结算顺序为免疫、减伤乘算、吸收盾、实际伤害；吸收盾跨机制按时间消耗。
- 每名成员只与上一条命中自己的机制相加，默认相隔超过 10 秒刷新，不继续累计更早机制。
- 参考最大生命默认留空；压力大于等于有效最大生命时标红。
- 个人减伤仅作用自己，外部与团队技能按实际目标计算。

## 验收标准

- [x] 50/60/80/30 万示例输出 50/110/140/110 万
- [x] 半场交错时按成员分别寻找上一机制
- [x] 物理/魔法、免疫、乘算减伤、盾消耗和生命提升正确
- [x] 未填写参考血量时不产生虚假致死判断
- [x] 缺少 WCL 数值的机制不参与压力计算并给出提示

## 验收结果

- 17 项核心测试覆盖直接伤害、跳伤、目标分组、相邻压力、伤害类型、免疫、乘算减伤、逐人/共享盾、生命提升和个人减伤。
- 内置示例在编辑页与只读页实际显示 50/110/140/110 万；持续机制显示原始总量和平均 DPS。
- 参考最大生命为空时致死状态为未知；压力等于有效最大生命时按致死处理。
- WCL 未知读条、持续时间和伤害保持 `null`，检查面板提示补充；`0` 仍作为明确零值参与显示与冲突判断。
