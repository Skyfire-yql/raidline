# 主题与极简界面

## 基本信息

- 优先级：P1
- 状态：已完成
- 提出时间：2026-08-04
- 目标版本：Raidline v2

## 目标

把全站改为信息清楚、时间轴优先的表格式工具，并提供跟随系统、亮色和深色三档主题。

## 功能要求

- 首页只保留创建、WCL 导入、预设和最近计划。
- 编辑器左右表格可收起，手机端改为抽屉，中央时间轴始终可操作。
- 主题作为当前设备偏好保存，跟随系统时实时响应系统主题变化。
- 主题在页面绘制前生效，避免闪烁；只读页使用同一套主题。

## 验收标准

- [x] 三档主题均可切换并在刷新后保持
- [x] 系统主题变化能实时反映
- [x] 首页、编辑器和只读页均使用表格式界面
- [x] 桌面与手机端均可完整编辑
- [x] 自动测试、生产构建和浏览器验收通过

## 验收结果

- 启动脚本会在首屏绘制前应用设备主题；“跟随系统”注册系统主题变化监听。
- 桌面端已检查左右栏收起、属性表、暗色/亮色切换和自动保存。
- 390×844 手机视口已检查首页、默认收起的左右抽屉、完整属性表单和只读页。
- TypeScript 严格检查、ESLint、核心单元测试、接口集成测试和生产构建通过。
