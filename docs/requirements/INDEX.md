## 记录约定

- 文件名使用 `YYYY-MM-功能名称.md`，例如 `2026-08-大米排轴.md`
- 优先级使用 `P0`、`P1`、`P2`、`P3`；数字越小越优先
- 状态使用“想法”“待确认”“待开发”“开发中”“已完成”或“暂停”
- 一项需求对应一份文档；范围明显不同的需求请拆开记录
- 截图、草图和参考资料放在 `assets/`，并从需求文档中使用相对路径引用
- 每次调整范围或验收标准时，在需求文档的“变更记录”中追加一行
