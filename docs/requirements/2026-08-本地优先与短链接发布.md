# 本地优先与短链接发布

状态：已实现，取代旧的服务器自动保存、恢复密钥和个人预设 JSON 流程。

## 核心约束

- IndexedDB 保存工作副本、检查点、目录缓存和设置；本地编辑不发送服务器写请求。
- 发布冻结点击瞬间的计划快照；上传期间的新修改继续留在本地并显示为未发布。
- 分享 ID 为 16 位 Base62，编辑 ID 为 4 位 Base62；编辑 ID 仅做路径匹配，不作为安全凭证。
- 服务端数据目录为每条链接只保存最新版；覆盖、发布为新链接和删除都必须由玩家明确触发。
- 目录条目按版本发布，预设引用机制 ID；应用后写入完整机制快照和来源版本，升级由玩家手动选择。
- 旧 v1/v2 计划本地迁移为 v3；旧服务端测试记录和链接不迁移。
