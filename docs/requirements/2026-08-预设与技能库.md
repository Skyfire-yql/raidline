# 预设与技能库

## 基本信息

- 优先级：P1
- 状态：已完成
- 提出时间：2026-08-04
- 目标版本：Raidline v2

## 目标

提供可编辑、可校验的正式服核心技能框架，并让用户在当前设备保存和复用完整计划预设。

## 功能要求

- 技能分为团队、单体外部和个人范围；必须先选择职业，再从该职业技能中选择。
- 新计划只内置技能名称、归属、范围和非数值简介；正式数值保持空白，由用户填写。
- 旧计划数值原样保留并标记为旧数据，不被新目录自动覆盖。
- 内置“基础机制示例”，仅包含机制名称、时间与说明；应用时保留成员、分组和技能库，替换战斗/阶段/机制并清空分配。
- 个人预设保存完整计划到当前设备，支持 JSON 导入、导出、应用和删除。
- 应用个人预设时替换完整计划并可撤销。

## 验收标准

- [x] 三种技能范围与人数上限警告正确
- [x] 新技能未知值与明确为 0 能区分
- [x] 内置预设保留团队数据并清空旧分配
- [x] 个人预设可在刷新后恢复并完成 JSON 往返
- [x] v1 计划可读取、编辑并保存为 v2

## 验收结果

- 新计划目录只提供名称、职业/专精归属、范围和非数值简介；正式数值保持未知并有目录版本标识。
- 个人技能在分配面板中固定显示“作用于施放者本人”，目标编辑器不会提供无效选择。
- 内置预设替换战斗信息、阶段和机制，保留成员、分组和用户技能库并清空分配；个人预设完整替换且进入撤销栈。
- IndexedDB 保存、JSON 校验/往返、v1→v2 内存迁移和首次编辑持久化均由测试或接口验收覆盖。
